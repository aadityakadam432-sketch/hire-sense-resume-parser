# hire-sense-resume-parser

AI-powered Resume Parser & ATS Analyzer

## Features
- PDF/DOCX/TXT resume parsing
- NLP-based information extraction
- Skills extraction
- ATS score
- Job description matching
- Resume history
- Dashboard & charts

## Tech Stack
- Python
- Flask
- PyMuPDF
- python-docx
- spaCy
- SQLite
- Chart.js
- HTML/CSS/JavaScript

## Installation

git clone YOUR_REPOSITORY_URL
cd HireSense

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python -m spacy download en_core_web_sm

python app.py
